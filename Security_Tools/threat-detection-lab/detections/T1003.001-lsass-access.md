## What the Attack Did
Used ProcDump (Sysinternals) to create a full memory dump of
the lsass.exe process. LSASS (Local Security Authority Subsystem
Service) stores credential material in memory including NTLM
hashes and Kerberos tickets. An attacker with this dump can
extract plaintext passwords offline using tools like Mimikatz,
enabling lateral movement across the entire environment.

## False Positive Considerations
- ProcDump is a legitimate Sysinternals tool used by developers
  and support engineers for crash dump analysis
- Legitimate use: debugging application crashes, not targeting lsass
- Key differentiator: legitimate ProcDump use targets application
  processes not lsass.exe specifically
- Any ProcDump execution targeting lsass.exe should be treated as
  malicious until proven otherwise

## Triage Steps
1. Confirm the target process is lsass.exe — automatic escalation
2. Identify who ran the command and from what parent process
3. Check if a dump file was successfully created on disk
4. Immediately isolate the endpoint if dump was successful
5. Assume credentials are compromised — initiate password reset
   for all accounts that logged into this machine

## Escalation Decision
**Escalate: Yes — immediately.** Any successful LSASS dump
represents a Critical incident. Credentials should be treated
as compromised. Escalate to Tier 2/3 and initiate IR process.

## Analyst Notes
